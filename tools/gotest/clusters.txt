# that matches a cluster key wins (go run ./tools/gotest report shows the keys). An owner is a step
# id (7.3, 9.5, ...), or one of:
#   bug        a gocpp bug with no plan step: to be fixed (a regression test of our own first)
#   by-design  gocpp differs from Go on purpose (docs/spec/language.md) and the difference is not
#              detectable before running: the manager decides whether to relax it
#   matcher    text of a diagnostic: gocpp's message differs from gc's (a wording decision)
# docs/guides/conformance.md describes the workflow (go run ./tools/gotest triage results.json).
